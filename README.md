# EthioCareer
Job and Internship managment system for Ethiopians.

#EthioCareer is a software application that connects job seekers and employeers in Ethiopia. Job seekers can create profiles,search for job and internships,apply and track application status. Employeers can post vacancies and review applications, while administrators manage user and monitor posting.
